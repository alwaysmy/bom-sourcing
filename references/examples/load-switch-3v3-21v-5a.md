## 5. 风险与边界

1. **eFuse ≠ 普通 load switch**：TPS25947 系列是"可调限流 eFuse"（限流点 0.5~6A 可设），适合做过流/浪涌保护；若只要通断+使能，SIP32434 / HS2950P.M 更直接。选型时要区分"额定通流"和"限流门限"。
2. **3.3V 下的通流能力要打折**：低压时 Rds(on) 上升、SOA 变窄，5A 只是常温标称，必须回手册核 Vgs=3.3V 曲线。
3. **立创参数栏覆盖不全**：该类目里"最大连续电流"等键只有部分条目填写，靠参数筛选会漏料 → 本次改用"全量抓取 + 客户端过滤"（`scan_hv_switch_full.py`），最终 81 条里只有 7 条同时满足 3.3V 与 5A。
4. **替代料接口对这两颗返回 0 条**（C3662799 / C47345802 都是新料），没有官方替代建议。
5. **数据手册直链失效**：`https://datasheet.lcsc.com/{pdfDESProductId}.pdf` 目前只返回 101–117 字节的跳转 HTML；可用的是商品页 `https://item.szlcsc.com/{productId}.html` 里 `pdfFileDetailVO` 的 `atta.szlcsc.com` 签名直链（带 Expires/Signature 参数）。
