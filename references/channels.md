# 渠道与采购执行

> 目标是回答：**这一行料，去哪买、买多少、什么时候不该省那点钱。**
> 价格为 2026-11 快照；渠道政策会变，下单前以页面为准。

## 1. 渠道性格

| 渠道 | 强项 | 弱项 | 适合 |
|---|---|---|---|
| **立创商城**（szlcsc） | 正品可追溯、有发票、参数结构化、阶梯价、可直推嘉立创 SMT；接口可程序化 | 单价常高于淘宝；有最低运费/起订；整盘约束 | 核心器件、贴片料、需要发票、批量 |
| **淘宝** | 散卖、包邮、单件也能买、同型号常有更低价 | 翻新/散新/拆机/涂标；无参数结构化，靠详情页文字 | 阻容感、二极管、LED、模块、样品 |
| **1688** | 批发价、MOQ 明确 | 需议价、质量参差、起订量高 | 单品类成百上千件、结构件、线材 |
| **京东工业 / 得捷 / Mouser** | 正品、有票、交期明确 | 贵、英文站、个人难开票 | 急件、军工/车规、立创缺货 |

结论一句话：**便宜料看淘宝，核心料看立创，量大看 1688，急件看京东/得捷。**

## 2. 按数量分流（`bom.py` 的实现规则）

| 采购量 | 建议 | 说明 |
|---|---|---|
| ≤ 10 | 淘宝优先 | 立创最低运费/起订摊到 10 件上不划算；散卖包邮正好 |
| 11–100 | 立创 vs 淘宝 比价 | 差价不大时选立创（正品、发票、可贴片） |
| > 100 | 立创阶梯 / 1688 | 阶梯价开始起作用；单品类可去 1688 谈 |
| 任意量，且是 MCU/电源/晶振/连接器 | 立创优先 | 核心件翻新风险成本远高于差价 |

例外：BOM 里已有立创编号（C 开头）的一律立创；目标是一次贴片（SMT）的，料必须在立创/嘉立创体系内，
因为外部来料需要寄件且要额外审核。

## 3. 立创商城 ↔ 嘉立创 SMT 的关系（常被误解）

- **库存和价格是两个系统**：商城（szlcsc）和 SMT（jlcpcb）各自独立，不能假设商城有货 SMT 就有。
- **商城买的料不能随 PCB 一起寄**：PCB 订单和元器件订单是两条物流。
- 贴片料只能在 SMT 下单时选，分**基础库 / 扩展库 / 推荐库**；**扩展库按型号数量收费**（每多一个型号多一笔），
  所以"把 3 个 10k 合并成 1 个 C 号"这种物料归一化能直接降报价。
- 嘉立创手动配单的输入格式是 `10K 5%`、`100PF 10V` 这种"值 + 精度/耐压"写法，**不是**型号；
  用 `10kΩ 1% 0603` 这种带符号的写法反而搜不出来。

## 4. 淘宝 / 1688 / 京东（实测，2026-11）

三家都**没有可用的免登录 HTTP 接口**（淘宝返回登录壳、1688 返回空壳、京东 302 到风控页）。
可行做法只有两种：带登录态的真浏览器，或付费 Apify MCP。本项目不内置爬虫。

### 淘宝（需要登录态浏览器）

- 本机可用路径：Kimi WebBridge daemon + Edge（Tabbit 没有淘宝登录态 → 结果区空白、卡片 0，
  这种"卡片 0 但 `__last_search_params` 正常"的表现是**登录态过期**，别误判成反爬）
- **销量排序不能靠 URL**：`&sort=sale-desc` 实测无效；必须在结果页点「销量」标签
  （内部排序键 `_coefp` → `_sale`，结果数 4800→8088，URL 不变）
- 单页 46–48 条；广告位销量为空要过滤；卡片价是**起价**
- 计量陷阱：电阻常按「100 个/包」卖（¥2.86/包 = 0.0286 元/只），芯片可能按「(10个)」一管卖
  → 比价前必须折算成**元/只**
- 限流实测：40+ 次请求、间隔 3–5 秒，零验证码；建议同站串行 ≥3 秒、每关键词 1 页、连 20 次歇 30–60 秒

### 1688（免登录，最适合走量）

- 检索可用；**销量排序有 URL 参数且生效**：`&sortType=va_sales360&descendOrder=true`
  （实测 soldCount 降序 32000 / 6000 / 5600…）
- 返回含价格区间、起批量、回头率、公司名
- **阶梯价取不到**：详情只给「¥2.00~¥17.00 1个起批」，没有 N–M 件台阶 → 走量价必须人工询盘
- 反直觉实测：STM32 裸片淘宝 ¥1.02–1.45 vs 1688 ¥4.00–5.15 → **小批量淘宝更便宜**；
  1688 的优势在大数量与对公，但当前拿不到阶梯价，无法用数据证实

### 京东（少量正品要发票）

- 首屏 30 条可用（免登录/登录态均可），但字段结构与淘宝完全不同（无销量文本，有
  `favorableRate`/`commentCount`）；结果以开发板套件为主 → 不适合 BOM 批量比价

### 海外分销商（Mouser 中国 / DigiKey 中国）

- **纯 HTTP 一律 403**：`digikey.cn` 是 Akamai 拦截、`mouser.cn` 是 DataDome JS 挑战；
  两者都只能走**真浏览器**（`scripts/distributor.py`，复用 Kimi WebBridge）。
- 返回的是**含税人民币价**（Mouser 中国显示 ¥ 且已含 13% 增值税），可以直接和立创比；
  不要再去乘汇率。
- 实测同一颗 TI eFuse：

  | 渠道 | 型号 | 1 只 | 10 只 | 25 只 | 100 只 | 1000 只 |
  |---|---|---|---|---|---|---|
  | 立创 | TPS259472ARPWR | 6.24 | 5.13 | — | 4.52 | **3.38** |
  | Mouser 中国 | TPS259472ARPWR | 16.9387 | 12.5091 | 11.3791 | — | — |
  | DigiKey 中国 | TPS259474LRPWR | 17.43 | — | — | — | — |

  → 立创约为海外 **1/4~1/3**，且没有起订量门槛；海外站的定位是「立创没有的型号 / 大厂料号」。
- 坑：Mouser 价格文本带千分位（`1 ¥1,183.0083`），解析前必须 `replace(",", "")`；
  DigiKey 把「型号 + 描述 + 品牌」塞在同一个 `<td>` 里，只能正则拆；
  DigiKey 搜索会先落到**品类卡片页**（"Product Index"），要点进具体品类才有商品行。

### 销量信号的价值边界

Spearman(价格, 销量) 实测仅 +0.09 / +0.08 / −0.07 / −0.31；且销量排序会把开发板套件顶到裸片前面。
**结论：销量只能当 tie-breaker，不能当主判据。** 立创的 `recentlySalesCount` 同理，用于「同参数多候选取谁」。

## 5. 比价时容易踩的坑

| 坑 | 说明 |
|---|---|
| 单价 vs 到手价 | 淘宝要加运费、立创要加运费/最低起订，比较必须用「总到手价」 |
| 阶梯价落档 | 立创价格随数量变，报 10 件的价不能用 100 件的单价 |
| 起订量 | `minBuyNumber`、整盘（`productMinEncapsulationNumber`）会强制放大采购量 |
| 同型号不同品牌 | 一个 MPN 对应多个 C 号，价格可差数倍；必须同时看品牌与库存 |
| 库存虚高 | `stockNumber` 与 `validStockNumber`/`usableTransitNum` 不同，能立即发的才算 |
| 交期 | `deliveryTimeWayDays` 是发货天数，不含快递时间；急件别只看库存 |
| **标题没写包装数量** | 按 1 只算出来的"单只价"只是假设 → 一律标 **不可比**，不许直接跟立创比 |
| **非料件混进结果** | 开发板 / 成品模块 / 混装包 / 系列链接的价格不能折算单只价 → 默认剔除（`taobao.py --all` 才显示） |
| **成色与真伪** | 见 §5.1：默认只标注，量产/高可靠才剔除 |

### 5.1 成色（拆机 / 散新 / 翻新）怎么处理

口径（2026-11-11 定）：**用户没要求量产或高可靠时，拆机件是可用的，只标注；提了才筛选。**

| 成色 | 判定词（卖家标题） | 默认（打样/维修） | 量产 / 高可靠 |
|---|---|---|---|
| 翻新 | 翻新、打磨、抛光、重打字、改标、洗标 | ⚠ 标注 | ⛔ 剔除 |
| 拆机 | 拆机、拆板、二手、回收、议价、旧件 | ⚠ 标注（可用） | ⛔ 剔除 |
| 散新 | 散新、散装新、库存散 | ⚠ 标注（可用） | ⛔ 剔除 |
| 国产替代 | 国产、兼容、可代替、代用、替换型 | ⚠ 标注 | ⚠ 标注（要看具体件） |
| 原装 / 全新 | 原装、正品、全新、原厂 | ✔ 标注为**卖家自述**（未核） | ✔ 同样只是自述 |

两条硬规矩：

1. **「原装正品」是卖家自述，不是证据**。标题写「全新原装」不代表是全新原装 —— 必须实物/授权渠道佐证。
2. **价差异常要顶掉成色自述**：淘宝单价 < 立创同型号的 **40%** 时，标「价差异常（立创的 0.0N×，可能非全新原厂）」。
   实测样例：`STM32F103C8T6` 标题「全新原装」标 ¥1.02–1.84，立创 ¥9.12 → 差 5–9×，基本不可能是全新原厂。

触发量产口径的方式：`pick.py` 句子里出现「量产 / 批产 / 车规 / AEC-Q / 工业级 / 高可靠 / 不要拆机 / 全新原装」，
或显式 `--production`。切换后比价只按「全新原装/未标明」取证，翻新/拆机/散新直接排除并说明。

## 6. 交付给用户的报价单里必须有什么

1. 每行的**立创编号 + 品牌 + 封装 + 实际采购量**（不是需求数量）
2. **单价 + 小计**，并写明取价时间与数量档
3. **指标核对结论**（✔ / ✘ / ? 都要有），`?` 单独列出待确认
4. **渠道建议 + 理由**（不是只写"淘宝"两个字）
5. **风险提示**：EOL / 停售 / 涂标 / 库存不足 / 需要整盘

## 7. 环境坑（本机实测，会浪费时间的）

| 现象 | 原因 | 处理 |
|---|---|---|
| `www.lcsc.com` / `wmsc.lcsc.com` 请求失败（curl 000、Python `SSLEOFError`） | 这两个域**不能走代理** | 直连；`lcsc.py` 的 `intl_detail()` 已内置 `ProxyHandler({})` 绕开代理 |
| `lcsc` / `jlcpcb` 等 Python 包报 `InvalidURL: Invalid port ':1]'` | 本机 `no_proxy` 含 `[::1]`，httpx 解析崩 | 用前 `$env:no_proxy=$null` |
| `curl -sI` 第一行是 `HTTP/1.1 200 Connection established` | 那是代理隧道，不是真实状态码 | 看第二行状态码 |
| `pip install` 取不到任何包 | 镜像源失效 | 加 `--index-url https://pypi.org/simple` |
| 淘宝结果区空白、卡片 0 但参数正常 | 登录态过期，不是反爬 | 重新登录浏览器 |
