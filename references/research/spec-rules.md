## 2. 无源器件

### 2.1 电阻

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 阻值 | 硬 | 必须相同（E24/E96 系列内） |
| 精度 | 硬（分压/采样）/ 软（限流/上拉） | 采样电路 ≤1%，上拉可用 5% |
| 功率 | 硬 | ≥ 2× 实际功耗 `[经验]` |
| 封装 | 硬（焊盘） | 0805/0603 按板设计 |
| 温度系数 | 条件硬 | 精密/分流采样 ≤50ppm/℃ |

**可放宽**：品牌、包装（整盘/拆盘）、精度（余量内可降一档）。

**封装功率速查** `[标准]`：0402≈63mW / 0603≈100mW / 0805≈125mW / 1206≈250mW / 2512≈1W。

**判据**：`P_rated ≥ 2 × I²R`；高压场合还要看**工作电压限制**（0805 通常 ≤150V，别只看功率）。

**价格带** `[实测]`：
- 0805 1% 10kΩ（厚声 C17414）：100 → ¥0.0202 / 1000 → ¥0.0154 / 5000 → ¥0.0108，库存 39KK+
- 0805 1% 10kΩ（富捷 C2907219）：100 → ¥0.013992 / 5000 → ¥0.008712

**坑**：
- 精度虚标：标 1% 实测 5%。关键位抽测。
- 功率不足：0603 当 0805 用，长期过热漂移。
- 翻新：电阻单价低，翻新少；但**拆盘混料**（不同精度混装）常见。
- 大阻值（>1MΩ）受潮后阻值下降，高湿环境要选防潮型。

### 2.2 电容 —— MLCC（陶瓷）

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 容值 | 硬 | 相同（注意实际容值受直流偏压影响） |
| 耐压 | 硬 | **≥1.5~2× 工作电压**（II 类介质尤其） |
| 介质 | 硬 | X7R/X5R 可互换；**Y5V/Z5U 绝不能替代 X7R** |
| 容差 | 条件硬 | 定时/滤波 ±10%，去耦 ±20% 可 |
| 封装 | 硬 | 焊盘 + 耐压/容值能力 |

**核心机理（这是 MLCC 最容易被忽略的坑）** `[手册]`：
- II 类介质（X5R/X7R/Y5V）在**额定直流电压下容值衰减 35~65%**（EPCI 论文实测）；
- 3.3V 实际工况下衰减 12~32%；
- 极端案例：1µF/6.3V X5R 加 3V 直流后仅剩 **0.36µF（−64%）**（ElectronicDesign 实测）。
- 工程结论 `[经验]`：**Class II MLCC 工作电压不要超过额定值的一半**；3.3V 轨至少用 6.3V 以上，推荐 10~25V。
- 介质温度特性：X7R −55~125℃ ±15%；X5R −55~85℃ ±15%；**Y5V −30~85℃ +22/−82%**（几乎不能用）。

**可放宽**：品牌、包装、容差（去耦场合）、精度等级。

**价格带** `[实测]`：
- 0805 10µF/25V X5R ±10%（三星 C15850）：20 → ¥0.2574 / 200 → ¥0.206 / 2000 → ¥0.1578
- 0805 10µF/25V X5R（华瓷 C19103847）：20 → ¥0.194275 / 3000 → ¥0.112195
- 0603 100nF/50V X7R（HRE C3012381）：100 → ¥0.025 / 8000 → ¥0.013

**坑**：
- **Y5V 冒充 X7R**：常温测容量正常，高低温直接掉 80%。识别：看型号字母（Y5V/Z5U 直接毙），或高低温箱抽测。
- **耐压虚标**：标 50V 实为 25V 料。高压位（>24V）必须抽测耐压。
- 容值虚标：低价高容料实际容值只有标称 60~70%。
- 焊接裂纹：MLCC 怕机械应力，板弯/手工烙铁过热会裂，表现为短路或漏电。

### 2.3 电容 —— 铝电解

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 容值 | 硬 | 相同或更大（滤波可升） |
| 耐压 | 硬 | ≥1.5× 工作电压 |
| 纹波电流 | **硬（最易忽略）** | ≤0.8× 额定（120Hz 基准） |
| ESR | 条件硬 | 开关电源输出必须低 ESR 型 |
| 尺寸/脚距 | 硬 | 插件脚距 2.5/5mm 不同 |
| 寿命 | 条件硬 | 105℃ 型 vs 85℃ 型 |

**寿命机理** `[手册]`（TDK）：遵循 **Arrhenius 10℃ 2 倍定律** —— 温度每降 10℃，寿命翻倍。105℃/2000h 的电容在 65℃ 下理论寿命 ≈ 2000h × 2^4 = 32000h（≈3.6 年连续运行）。
→ 长期运行的电源，**必须选 105℃ + 高寿命（5000h+）**，85℃ 普通型不要用在发热位置。

**可放宽**：品牌、容值（+50%）、尺寸（空间允许时用更大更耐用）。

**价格带** `[实测]`：100µF/25V 纹波 88mA@120Hz（KNSCHA C4747964）：10 → ¥0.2228 / 100 → ¥0.1822 / 1000 → ¥0.132088

**坑**：
- **套壳电容**（小容值装大外壳）：称重/测容值可识别，是电源类最大坑。
- 翻新拆机电容：引脚有锡痕、顶部防爆槽被压过。
- 耐压/纹波虚标：标 105℃ 实为 85℃ 料。
- 存放过久（>2年）未通电，漏电流增大、容量下降 —— 老库存要"老炼"后再用。

### 2.4 电容 —— 钽电容

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 容值 | 硬 | 相同 |
| 耐压 | **硬，≥2×** | 钽对过压极敏感，失效模式是**短路** |
| ESR | 条件硬 | 开关电源场合要低 ESR |
| 封装（壳号） | 硬 | CASE-A/B/C/D 尺寸不同 |

**关键规则** `[手册]`：
- 钽电容**失效即短路**（不像铝电解会干涸），所以**必须 2× 以上降额**，且建议加限流或串联电阻。
- 上电瞬间 dv/dt 过大会击穿，**必须限制浪涌电流**（datasheet 有 max surge current 规定）。

**可放宽**：品牌（AVX/KEMET vs 国产湘怡中元，价差约 2×）、容差。

**价格带** `[实测]`：
- 10µF/16V CASE-A ESR 3Ω@100kHz（AVX C7171）：20 → ¥0.9633 / 60 → ¥0.843
- 同规格国产（湘怡中元 C119051）：50 → ¥0.5567 / 500 → ¥0.4891

**坑**：
- 翻新/散新钽电容极多（拆机后 ESR 上升）。
- 用铝电解冒充钽（体积/重量不同）。
- 国产低价钽漏电流大，低功耗电路待机电流超标。

### 2.5 电感 / 功率电感

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 电感量 | 硬 | 相同（±20% 内） |
| 饱和电流 Isat | **硬** | **≥1.3× 峰值电流** `[经验]` |
| 直流电阻 DCR | 条件硬 | 影响效率与压降，越低越好 |
| 额定电流 Irms | 硬 | ≥ 工作电流（温升 40K 基准） |
| 封装/尺寸 | 硬 | 焊盘 + 高度限制 |
| 屏蔽 | 条件 | 屏蔽型 EMI 好，非屏蔽便宜 |

**判据**：`Isat ≥ 1.3 × I_peak`，其中开关电源的 `I_peak = I_out + ΔI/2`，ΔI 通常取 I_out 的 20~40%。
饱和后电感量骤降 → 电流失控 → MOS 烧毁，这是 DCDC 炸机的第一原因。

**可放宽**：品牌、屏蔽（非 EMI 敏感可用非屏蔽）、精度（±20% 足够）。

**价格带** `[实测]`（CD32 10µH）：
- 益嘉源 C492261：10 → ¥0.2713（1A / DCR 342mΩ）
- 美铼 C915150：20 → ¥0.180405 / 600 → ¥0.11837（Isat 950mA / DCR 286mΩ）

**坑**：
- **Isat 虚标**（最常见）：标 3A 实际 1A 就饱和。识别：加载到额定电流看纹波是否突变。
- 用铁氧体磁芯冒充合金粉芯（大电流下饱和更早）。
- 绕线匝数不足 → 电感量偏低、DCR 偏低但纹波大。

### 2.6 磁珠

**必配参数**：

| 参数 | 关键性 | 判据 |
|---|---|---|
| 阻抗 @100MHz | 硬 | 相同或更高（噪声抑制量） |
| 额定电流 | 硬 | ≥ 工作电流（超流后磁珠饱和失效） |
| DCR | 条件 | 影响压降，电源线用低 DCR |
| 封装 | 硬 | 0603/0805 |

**注意** `[手册]`：磁珠不是电感 —— 它的作用是**高频损耗**（把噪声变热），直流几乎无阻抗。不可用电感替代磁珠做 EMI 抑制，也不可用磁珠替代储能电感（会饱和）。

**价格带** `[实测]`：
- 0603 120Ω@100MHz 2A DCR 50mΩ（村田 C14709）：50 → ¥0.0834 / 1500 → ¥0.0549
- 0603 220Ω 2.2A（TDK C76815）：10 → ¥0.1233

**坑**：额定电流虚标（大电流下磁珠饱和，阻抗归零，EMI 反而更差）；用 0Ω 电阻冒充磁珠。

## 3. 分立半导体

### 3.1 整流二极管

**必配参数**：Vr（反向耐压）、If（平均整流电流）、Vf（正向压降）、封装、trr（恢复时间）。

**判据**：
- `Vr ≥ 1.5 × V_reverse_max`（感性负载 2×）
- 市电整流：220V 峰值 311V → **必须 ≥600V，通用选 1N4007（1kV）** `[标准]`
- `If ≥ 1.5 × I_load`

**可放宽**：品牌（价差 7×）、封装（SMA→SMB 可上浮）、Vf（非低压场合）。

**价格带** `[实测]`（1N4007）：
- onsemi C53568：10 → ¥0.3551 / 100 → ¥0.2789 / 1000 → ¥0.2122
- 国产 R+O（SOD-123）C18199088：50 → ¥0.0553 / 6000 → ¥0.029545

**坑**：1N4007 假货耐压常只有 100~400V（市电直接击穿）；玻封管打磨重印；正品 Vf 0.9~1V，假货常偏低或偏高。

### 3.2 肖特基二极管

**必配参数**：Vr、If、Vf、封装、反向漏电 Ir。

**判据**：
- `Vr ≥ 1.5×`（高温场合 **2×**，因为肖特基漏电随温度指数上升）
- `Vf` 必须看**测试电流条件**（@3A 与 @1A 不可比）

**可放宽**：品牌（**价差 15×**）、Vf（非电池/非低功耗场合）。

**价格带** `[实测]`（SS34 SMA 3A/40V）：
- onsemi C154551：Vf 500mV@3A，10 → ¥2.37 / 100 → ¥1.7
- 国产 R+O C7420365：Vf 550mV@3A，20 → ¥0.2166 / 5000 → ¥0.111055

**坑**：
- **假 SS34 = SS14/SS24 重印**（耐流不足，大电流烧毁）
- Vf 虚标（标 0.3V 实测 0.6V）
- 高温漏电：普通肖特基 125℃ 时漏电可放大 100×，电池回路禁用

### 3.3 稳压二极管

**必配参数**：Vz **范围值**（不是标称值）、功率、封装、Izmin。

**判据**：
- 必须比 **Vz 范围**（如 5.1V 的 4.8~5.4V），同标称不同范围不可等价
- `P ≥ 2× 实际功耗`，且核算 `Iz=(Vin−Vz)/R` 是否超额定
- 精密基准不要用稳压管（温漂 ±5mV/℃），用 TL431/基准 IC

**价格带** `[实测]`（BZX84C5V1 SOT-23）：onsemi C47075 20 → ¥0.2472 / 200 → ¥0.196；国产 50 → ¥0.1124

**坑**：SOT-23 丝印相同（不同 Vz 外观完全一样，混料极其常见）→ 关键位必须抽测 Vz；功率虚标（标 500mW 实 200mW）。

### 3.4 TVS / ESD 保护

**必配参数**：Vrwm（反向工作电压）、Vclamp（钳位电压）、Ipp（峰值脉冲电流）、极性（单向/双向）、结电容。

**三条硬约束**（顺序不能错）：
1. `Vrwm ≥ 线路最高工作电压`（否则正常工作时漏电发热）
2. `Vclamp < 被保护 IC 绝对最大额定 × 0.8`（**这是选型第一约束**）
3. `Ipp ≥ 预期浪涌`（注意 8/20µs 与 10/1000µs 波形不可混比）

附加：**高速信号线（USB/HDMI/CAN）必须低容**（<1~5pF），否则信号畸变。单向/双向不可混（直流用单向，交流/差分用双向）。

**价格带** `[实测]`（SMBJ5.0A 5V 单向，钳位 9.2V）：
- Littelfuse C83333（Ipp 65.3A）：5 → ¥0.6617 / 50 → ¥0.5297
- 国产 R+O C19077558：10 → ¥0.2877 / 300 → ¥0.2001

**坑**：**假 TVS = 普通稳压管重印**（能量吸收能力差一个数量级，浪涌一来就烧）；Ipp 严重虚标；识别：TVS 结电容大、Vbr/Vrwm ≈1.1~1.2。

### 3.5 三极管（BJT）/ 数字晶体管

**必配参数**：类型（NPN/PNP）、Vceo、Ic、Pd、hFE、封装。

**判据**：`Vceo ≥ 1.5×`（感性 2×）、`Ic ≥ 1.5×`、`Pd ≥ 2×`；驱动继电器时核算 `Ib ≥ Ic/hFE(min)`，hFE 分档（O/Y/GR）**不能降档**。

**可放宽**：品牌、hFE 上限（过高易振荡）、封装。

**风险重点** `[实测]`：搜索 "S8050 贴片" 时**两条结果均显示"商品已停售"** —— 经典小信号管存在 EOL 风险，照抄老 BOM 会买不到。采购必须查在售状态。

**坑**：SOT-23 打磨重印极普遍；hFE 分档混乱（标 GR 实为 O 档，驱动不足）。

### 3.6 MOSFET

**必配参数**：沟道类型（N/P）、Vds、Id、**Rds(on)@实际Vgs**、Vgs(th)、封装、Qg。

**判据**：
- `Vds ≥ 1.5×`（电机/继电器等感性负载 **2×**，因为尖峰）
- `Id ≥ 1.3×`，但 **Id 是壳温 25℃ 理想值，必须用 Rds(on) 与温升复核**
- **Rds(on) 必须用相同 Vgs 条件比较！** `[实测]` 同 MPN `AO3400A`：AOS 标 48mΩ **@Vgs=2.5V**，UMW 标 17mΩ **@Vgs=10V** —— 数值差 3 倍是**条件差异，不是性能差异**。
- **3.3V MCU 直驱必须选 Vgs(th) ≤1.5V 且 Rds(on) 在 Vgs=2.5~4.5V 已达标**（逻辑电平 MOS）

**可放宽**：品牌（**价差 3.2×**）、Vds（非感性 1.3×）、Id（有散热核算时）。

**价格带** `[实测]`（AO3400A SOT-23 30V）：
- AOS C20917：5 → ¥0.543 / 500 → ¥0.3394
- UMW C347475：20 → ¥0.2119 / 3000 → ¥0.106

**坑**：
- **假 AO3400**（普通 NPN 或低规格 MOS 重印），Rds(on) 偏高、发热 —— 量 Vgs(th) 与 Rds(on)
- 翻新 MOS（拆机硅片已退化，Rds(on) 上升 20%+）
- SOT-23 的 N/P 沟道部分引脚定义不同，替换要核 pinout
- **只看 Id 不看 Rds(on) 是炸机主因**

## 4. 模拟与电源

### 4.1 运算放大器

**必配参数**：通道数、GBW、Vos、供电范围、轨到轨（RRI/RRO）、封装、静态电流。

**判据** `[经验]`：`GBW ≥ 3 × 目标信号带宽 × 闭环增益`（保守取 3~10×）；Vos 按直流精度要求；**低边电流采样必须 RRI**。

**可放宽**：品牌、GBW（非高速 1MHz 足够）、温度等级。

**价格带** `[实测]`：LM358（onsemi C7950）10 → ¥0.3308；国产 LM358P8（C54951947，GBW 1MHz / Vos 1mV）5 → ¥0.59877。

**坑**：
- **SOT-23-5 单运放至少有 5 种 pinout**，替换必查引脚排列
- 页面参数不齐全（只写"双运放 SOP-8"），无法凭页面比价 → 必须查 datasheet
- LM358/LM324 是拆机翻新重灾区
- 用最低供电 4.5V 的老运放跑 3.3V 单电源（工作异常）

### 4.2 比较器

**必配参数**：通道数、**输出类型（开漏/推挽）**、tpd、Vos、供电、共模输入范围、封装。

**判据**：开漏/推挽**不可互换**（开漏需上拉，推挽可直接驱动，开漏可线与）；tpd 决定最小可检测脉宽。

**坑** `[实测]`：同型号 LM393，onsemi C7955 标 tpd 300ns，ST C32901 标 tpd 1.3us —— **差 4 倍**，页面参数不可全信。开漏输出忘加上拉是新手常踩坑（输出永远高阻）。

### 4.3 LDO 线性稳压器

**必配参数**：Vin 范围、Vout、Iout、**dropout**、**Iq**、封装、PSRR。

**判据**：
- `Vin_max > 输入最高值（含瞬态）`；AMS1117 最大 15V，直连 12V 余量小
- `Vin_min − Vout > dropout + 纹波`（掉出 dropout 后 PSRR 崩溃、输出跟随下陷）
- `P = (Vin−Vout) × Iout`，**超过 0.5W 就要考虑换 DCDC**
- 电池设备：**Iq < 10µA**，AMS1117 的 5mA 静态电流是低功耗设计杀手

**可放宽**：品牌（**价差 5×**）、PSRR（数字电路 40dB 够）、精度（±2%）。

**价格带** `[实测]`：AMS1117-3.3 SOT-223 —— 500 → ¥0.7247，1000 → ¥0.139365（不同品牌，**价差约 5×**）。

**坑**：AMS1117 假货最多（实为 1117-ADJ 或 78L33 重印，带载掉压）；输入端必须 ≥10µF 否则自激振荡；SOT-223 标 1A 但无铜箔散热只能 0.5A。

### 4.4 DC-DC 开关电源

**必配参数**：拓扑（Buck/Boost/Buck-Boost）、Vin 范围、Vout、Iout、fsw、封装、外围需求（同步/非同步）。

**判据**：
- 拓扑不可混（Buck 芯片不能升压）
- `Iout ≥ 1.3×`
- 升压型：**输入电流 = Iout × Vout/Vin / η**，输入电容按输入电流算
- **替换芯片必须重算外围**（fsw / FB 基准 0.6V vs 0.8V vs 1.23V / 补偿网络）

**可放宽**：品牌（**价差 4×**）、fsw（非 EMI 敏感）、效率（小功率 80% vs 90% 可接受）。

**价格带** `[实测]`：MT3608 C84817 升压 2~24Vin → ¥0.5833@1（MT3608L ¥0.3411）；LM2596S-5.0 降压 TI C116713 → ¥10.1@1，UMW → ¥2.64@30。

**坑**：MT3608 / LM2596 假货翻新极多（带载掉压、效率低、烧 MOS）；廉价模块电感 Isat 不足 + 电容缩水（标 2A 实际 0.5A）；**电感 Isat 不足是 DCDC 炸机第一原因**。

### 4.5 电荷泵

**必配参数**：倍数/极性（倍压 2× / 反压 −Vin）、Iout、Vin、fsw、封装。

**判据**：倍数与极性不可混；输出电流能力小（几十~几百 mA）且随 Vin 下降；**飞电容耐压必须 ≥2× Vin**（倍压时承受双倍电压）。

**价格带** `[实测]`：ICL7660M/TR（华冠 C356724）5 → ¥1.1167 / 150 → ¥0.7927；瑞萨原厂 C7881 → ¥5.82@1（**价差 5×**）。

**坑**：翻新导致带载能力差、起振失败；飞电容用 Y5V 介质 → 容量随温度崩塌、纹波暴涨。

### 4.6 晶振 / 振荡器

**必配参数**：频率、**类型（无源/有源）**、**负载电容 CL**、精度 ppm、封装。

**四条硬规则**：
1. 频率**必须完全一致**（不存在"差不多"的频率）
2. **CL 必须与原设计匹配** —— 这是最容易被忽略的致命参数。CL 不同会让实际频率偏移（可达几百 ppm），串口/USB 通信失败。外部电容 `C = 2×(CL − C_stray)`
3. 无源 vs 有源不可换（无源需 MCU 内部振荡电路，有源自带输出）
4. 精度：串口 ±20ppm 够；USB/以太网需 ±10ppm；RTC 32.768kHz ±20ppm

**可放宽**：品牌、精度（非通信 ±30ppm）、温度等级（室内 −20~70℃）。

**价格带** `[实测]`：16MHz ±10ppm 9pF 3225（YXC C13738）5 → ¥0.5705 / 500 → ¥0.327655。

**坑**：晶振频率偏移超差（±100ppm 以上，串口误码率上升）；用频率计/示波器测实际频率；翻新晶振难辨，靠渠道。

## 5. 数字 / 接口 / 机电

### 5.1 MCU

**必配参数**：系列、Flash、RAM、封装、供电、外设集合、**引脚复用映射**。

**判据**：
- **同系列同封装才谈 drop-in**（STM32F103C8T6 → C6T6/CB，Flash 更大可替代更小）
- 跨系列只能"功能等价"，必须重验引脚映射与外设寄存器
- **RAM 不足是最隐蔽的坑**（编译可过、运行崩栈）
- 外设数量必须是需求的超集（ADC/串口/I2C/SPI/定时器）

**可放宽**：品牌（国产 GD32/APM32 同封装兼容，省 30~50%，**但必须验证 ADC/时钟/USB/低功耗**）、温度等级、Flash 余量。

**价格带** `[实测]`：STM32F103C8T6（ST C8734）1 → ¥9.12 / 250 → ¥6.3。

**坑**：
- **翻新/打磨 MCU 是最大风险**：读出 Flash 大小与丝印不符（C8 应 64KB）、UID 重复、擦写次数异常
- 国产兼容片：引脚兼容但 ADC 精度/内部时钟/USB 需重验
- EOL：老型号价格暴涨或断货，BOM 必须标生命周期

**同族常见配套** `[实测]`：CH340C（WCH C84681，USB 转串口 3.3/5V 2Mbps，**省晶振**）1 → ¥3.33 / 100 → ¥2.04；NE555DR（TI C7593）5 → ¥0.6598。

### 5.2 排针 / 排母

**必配参数**：间距、排数、每排针数、**安装方向（直/弯/立贴）**、镀层。

**判据**：间距**完全不可混**（2.54 / 2.00 / 1.27 / 1.00）；直针/弯针/立贴不可互换（弯针方向错等于报废）；**长排针（2.54-1×40P）可裁剪成任意短排针** —— 缺货时的合法应急手段 `[经验]`。

**可放宽**：塑高（1.5/2.0/2.5mm，非机构限制）、品牌、针长。

**价格带** `[实测]`：2.54-1×40P 直针 C2337 5 → ¥0.9725；2.54-1×6P C37208 10 → ¥0.2547。

**坑**：2.54 与 2.00 外观接近，插错会顶坏针座；铁针（磁铁可测）易断且难焊；塑高混料导致装配顶不到。

### 5.3 USB / Type-C 连接器

**必配参数**：类型、**引脚数（6P/16P/24P）**、安装方式（立贴/沉板/直插）、额定电流。

**判据**：**16P 与 24P 焊盘不同、不可互换**；16P 只能 USB2.0，要 USB3/PD 必须 24P；立贴/沉板/直插 PCB 开孔完全不同。

**价格带** `[实测]`：Type-C 16P 母座立贴（品赞 C2843970）1 → ¥3.0115 / 100 → ¥1.8335。

**坑**：廉价母座弹片疲劳后充电断续（最常见的售后问题）；16P 冒充 24P（外观相似，高速对缺失）；沉板/立贴混发。

### 5.4 端子 / 接线端子（XH/PH/VH/栅栏）

**必配参数**：**系列**、间距、针数、安装方式。

**判据**：XH=2.54 / PH=2.0 / VH=3.96 / ZH=1.5，**系列不可混**（间距接近但锁扣形状不同）；电流：XH≈3A、PH≈2A、VH≈10A、栅栏 10~15A。

**价格带** `[实测]`：XH2.54 立式座 3P（C19723937）5 → ¥0.5515 / 150 → ¥0.376。

**坑**：**只买座不买插头**是配单高频错误 —— BOM 必须"座 + 插头 + 端子"三件成套；XH 与 PH 强行互插会顶弯针。

### 5.5 继电器

**必配参数**：线圈电压、触点形式（NO/NC/1C）、触点容量（电流/电压）、脚位封装。

**判据**：
- 线圈电压**必须完全一致**（5/12/24V 不可混）
- 1C（转换）可替代 1A（用 NO 端），反之不可
- 触点电流：**阻性 ≥1.5×，感性 2~3×**（电机/灯）；**交流额定不能直接切直流高压**（灭弧能力差，触点粘连）
- **必须接续流二极管**（线圈断电反压会击穿驱动管）

**价格带** `[实测]`：SRD-05VDC-SL-C（松乐 C35449，5V 1C 250VAC）1 → ¥2.71 / 100 → ¥1.55。

**坑**：翻新继电器触点已烧蚀（吸合正常但接触电阻大、带载发热）；触点容量虚标（标 10A 切 3A 就粘连）；线圈匝数不足导致吸合力弱、抖动。

### 5.6 光耦

**必配参数**：输出类型、**CTR**、隔离电压、Vf、封装、通道数。

**判据**：
- **CTR 必须按最小值且考虑老化衰减**（CTR 随温度与时间下降，设计留 50% 余量）
- **PC817 很慢（µs 级），高速信号必须用 6N137 类逻辑输出光耦**
- 隔离电压安规红线不可降额（常见 3.75kV/5kVrms，安规场合需 UL/VDE 认证）

**价格带** `[实测]`：PC817（夏普 C66405）5 → ¥0.5723；EL357N（亿光 C42381015）10 → ¥0.3537。

**坑**：翻新光耦 CTR 已衰减（输出驱动不足、开关变慢）；CTR 分档（A/B/C/D）混料导致驱动失配。

### 5.7 保险丝 / 自恢复保险丝（PTC）

**必配参数**：类型（一次性/PTC）、额定电流、额定电压、封装、熔断速度。

**判据**：
- **一次性与 PTC 不可互换**（PTC 有阻抗且会反复动作）
- `I_rated = 1.3~2 × 工作电流`（太小误动作，太大不保护）
- **PTC 的 Ihold 才是额定值**，Itrip ≈ 2× Ihold；按 Itrip 选必误动作 `[经验]`
- `V_rated ≥ 1.5× 分断电压`（不足会拉弧不断）
- 快断(F) 保护半导体，慢断(T) 用于电机/容性启动

**价格带** `[实测]`：0805 PTC 6V/500mA（R+O C46640983）20 → ¥0.2332；1206 PTC 2A → ¥0.4949@5。

**坑**：PTC 参数认知错误（按 Itrip 选）；拆机保险丝已疲劳、动作特性漂移。

### 5.8 按键 / 开关

**必配参数**：类型（轻触自复位/自锁/拨动/船型）、尺寸、**脚距**、额定电流。

**判据**：自复位/自锁**行为完全不同**不可混；6×6 轻触有 4.5×6.5 等多种脚距，PCB 孔位不同；**轻触开关仅信号级（50mA），不能直接切负载**。

**价格带** `[实测]`：6×6×5 贴片轻触（金航标 C2837531）50 → ¥0.1153 / 2000 → ¥0.074。

**坑**：廉价品手感不稳、回弹差；拆机件触点氧化（需多次按压才响应）。

### 5.9 LED

**必配参数**：颜色（波长）、Vf、额定电流、封装、发光角度。

**判据**：颜色决定 Vf（红 1.8~2.2V，蓝白 2.8~3.4V），限流电阻必须按 Vf 算；**必须有限流电阻**；指示灯实际 2~5mA 就够（省电且亮度足）。

**价格带** `[实测]`：0603 红（C51933292，Vf 1.8~2.2V 20mA 620-625nm）100 → ¥0.01608 / 4000 → ¥0.00992。

**坑**：亮度/波长批次差异大（同型号不同批次色差明显）；混 bin 发货。

**坑**：
- **同 MPN 多 C 编号且库存差异大**（W25Q64 C179171 有货 1383，另一 C 号库存 0）→ 必须按 C 号去重选有货者
- 页面备注出现**"涂标""批次"** = 丝印被涂改，散新/翻新信号 `[实测]`

### 6.4 成品电源模块（隔离型）

**必配参数**：Vin、Vout、功率、隔离电压、封装（脚位）。

**判据**：**定压模块（5V±10%）不能宽压用**；功率按 **70% 使用**（模块散热差）；隔离电压安规件不可降额。

**价格带** `[实测]`：B0505S-1W（EVISUN C7465127，4.5~5.5Vin 79%）1 → ¥3.92 / 34 → ¥2.49。

**坑**：隔离电压虚标（标 3kV 实测 1kV 击穿）；廉价模块轻载效率极低、纹波大。

### 6.5 数字隔离器

**必配参数**：通道数、**方向配置**、隔离电压、速率、VDD1/VDD2、封装、CMTI。

**判据**：**方向配置必须匹配**（接反等于不工作）；隔离电压按安规选（加强绝缘≠基本绝缘）；强干扰/电机驱动需 CMTI >25kV/µs `[经验]`。

## 7. 跨品类通用选型启发式

### 7.1 排序原则（先硬后软）

| 优先级 | 规则 | 说明 |
|---|---|---|
| **硬** | 有货 | 库存 > 本次需求，或确认交期 |
| **硬** | 在售 | 剔除"停售/EOL/最后一批" |
| **硬** | 按 C 号去重 | 同 MPN 多 C 号，选有货者 |
| **硬** | 参数条件可比 | Vgs/测试电流/频率条件不同不可比 |
| 高 | **按目标数量取阶梯价** | 实测阶梯差 5~10×，不能用 1 片价 |
| 中 | 品牌可放宽 | 同规格价差 3~15×，优先低价品牌 |
| 中 | 多供应商 | ≥2 个品牌可选者加分 |
| 中 | 封装通用 | 0603/0805/SOP-8/SOT-23 优先 |
| 低 | 热度/库存量级 | 库存 >100K 视为通用料 |
| 低 | 外围不变 | 省验证成本 |

### 7.2 打分公式（可直接实现）

```
score = 0.40 * price_score      # 归一化到候选集最低价
      + 0.15 * brand_score      # 低价品牌加分，但不给 0 分（质量下限）
      + 0.10 * package_score    # 通用封装加分
      + 0.10 * popularity_score # 库存/销量量级
      + 0.15 * supplier_score   # 多供应商
      + 0.05 * inertia_score    # 外围元件不变
      + 0.05 * risk_score       # 无翻新/涂标/停售信号
```

**任一硬规则不通过 → 直接剔除，不参与打分。**

### 7.3 替代工作流（7 步）

1. 从原 BOM 提取 MPN + 关键参数（用 datasheet 补全商城缺失项）
2. 按品类 `critical` 列表做**硬约束过滤**（含余量系数）
3. 对通过者做**条件感知**参数比较（同条件才可比）
4. 按目标数量取阶梯价，排序
5. 应用风险信号剔除/降权
6. 输出 **top3 候选 + 差异清单**（哪些参数变了、影响什么）
7. **高风险品类（电源/MCU/晶振/隔离）人工确认后才可下单**

### 7.4 风险信号 → 动作

| 信号 | 含义 | 动作 |
|---|---|---|
| 价格 < 市场价 30% | 翻新/散新/虚标 | 降权或要求抽测 |
| "停售/停产/最后一批" | EOL | 剔除（除非库存够本次用量） |
| 备注含"涂标/翻新/散新/批次混" | 丝印被涂改 | 剔除 |
| 同 MPN 多 C 号、库存差异极大 | 不同批次/渠道 | 选有货者，BOM 标 C 号 |
| 关键参数缺失或无比对条件 | 无法机械比对 | 标"待人工确认"，不自动替代 |

### 7.5 十条经验总结

1. **品牌是最安全的降本维度** —— 同规格换国产常省 3~10×，实测 SS34 达 15×。
2. **参数必须带测试条件** —— 同 MPN 的 Rds(on) 因 @2.5V 与 @10V 差 3 倍，是条件不是性能。
3. **MLCC 耐压要 2×** —— 直流偏压下容值掉 35~65%，这是最反直觉的一条。
4. **钽电容失效即短路** —— 必须 2× 降额 + 限浪涌。
5. **电感 Isat 是 DCDC 炸机第一原因** —— 必须 1.3× 峰值并看波形验证。
6. **MOS 只看 Id 不看 Rds(on) 必炸** —— Id 是 25℃ 理想值。
7. **晶振负载电容 CL 不匹配会偏频** —— 串口/USB 直接通不了。
8. **3.3V 直驱 MOSFET 必须逻辑电平** —— Vgs(th) ≤1.5V，否则线性区烧毁。
9. **保险丝按 Ihold、按工作电流 1.3~2× 选** —— 别按 Itrip，会误动作。
10. **老 BOM 先查在售** —— 实测 S8050 已停售，照抄会买不到。
