# pick.py 集成淘宝/1688 比价与样品可得性

> 最后更新：2026-11-05　｜　改动脚本：`D:\WorkDesigns\3_WorkTools\skills\bom-sourcing\scripts\pick.py`（单文件）
> 原始数据：`D:\WorkDesigns\3_WorkTools\Bom_Flow\probe\taobao-pick\`（`pick_<型号>_<站点>_<时间戳>.json`、`runs\*.txt`）

## 结论

`pick.py` 现在能按数量自动判断"要不要看淘宝"：**少量（≤10 只）默认去淘宝/1688 摸单只价与样品可得性，11~100 只只给立创，>100 只不查淘宝、直接指向 1688 询盘**。输出多一列「样品可得性」（能否买 1 只、包装数量、归一单只价）与一段渠道结论句。混装包、开发板、系列链接、数量区间价按规则剔除，不参与比价。

实测 5 组料，淘宝单只价普遍比立创低 **56%~99%**（小批量散卖），但**多数链接有起订量**（5000 只/份、2000 只/份），真正的"打样 1 只"要靠标题未标数量的散卖链接；1688 同款比淘宝贵一档、但比立创便宜（STM32F103C8T6：1688 ¥1.49 vs 立创 ¥9.12）。

## 改动点

| 位置 | 内容 |
| --- | --- |
| `_ASSORT_RE` | 混装/套装关键词（芯片包、元件包、套装、套餐、样品盒、整盒、`N 种`…） |
| `_DEVBOARD_RE` | 开发板/套件（开发板、最小系统、核心板、仿真器、下载器、烧录器、套件） |
| `_RC_VAL_RE` / `_GLUED_VAL_RE` / `_GLUED_CAP_RE` + `_looks_series()` | 判"一条链接挂多个阻值/容值"的系列链接。只认电阻/电容单位，左边界不能紧贴字母数字，否则 `AO3400A/30V/5.8A` 会误判 |
| `_market_usable(x)` | 混装 / 开发板 / 数量区间 / `unit_confidence=low` → 剔除 |
| `sample_info(x)` | 单条结果 → 样品可得性（`sample_ok/pack/unit_price/pack_text/sample_text/shipping_note/shop_type/assumed/note`） |
| `_shop_type()` | 旗舰店 / 专营店 / 企业店 / 散货·配单 / 普通店 |
| `_shipping_note()` | 标题含"包邮"→包邮；单价 <¥1 →"运费另计（≈¥8-12，单价低于运费建议凑单）" |
| `taobao_plan(args)` | 数量 → 比价型号数：`--no-taobao`=0；`--taobao N`=N；`qty>100`=0；`qty≤10`=`--taobao-sample`(默认 3)；11~100=0 |
| `market_compare()` | 打表 + 渠道结论；`_dump_market_raw()` 按型号落盘原始 JSON |
| `_ratio_text()` | 价差文案：省 90% 以上改说"便宜 N×"，避免"省 100%" |
| `cmd_pick()` 尾部 | 按 `taobao_plan()` 决定调不调比价；>100 只且未 `--no-taobao` 时打印批量提示 |

判定规则（`sample_info` 分支顺序，命中即返回）：

1. 开发板/套件 → `✗ 开发板/套件`
2. 混装包（`assortment` 或 `_ASSORT_RE`）→ `✗ 混装包`
3. `unit_note` 以「数量区间」开头 → `✗ 区间价`
4. 标题能解析出包装数量 `pack_qty` → `pack≤10` 记 `✓ 可打样`，否则 `✗ 最小 N 只`
5. 标题像系列链接（`_looks_series`）→ `✓ 可打样（系列链接）`，不给单只价
6. 其余 → 按 1 只计（`assumed=True`），`✓ 可买 1 只`

## 默认出门淘宝的规则

| 数量 | 是否查淘宝 | 说明 |
| --- | --- | --- |
| `--qty ≤ 10` | 是（默认取前 3 个型号，`--taobao-sample N` 可调） | 打样/少量：淘宝散卖更便宜，但要把运费（≈¥8-12）算进去 |
| `11 ≤ --qty ≤ 100` | 否 | 立创阶梯价通常最优，淘宝零售价不一定随量降 |
| `--qty > 100` | 否，且打印批量提示 | 走 1688 询盘/原厂代理（1688 阶梯价不公开，需人工问） |
| `--taobao N`（显式） | 是，取前 N 个型号（忽略数量阈值） | 想比价就显式给 |
| `--no-taobao` | 否 | 完全关闭比价（离线/不想开浏览器时） |

## 最终 CLI 形状

```
python scripts\pick.py "找 3.3V 1A 的 LDO" [--qty N] [--limit N] [--pages N]
                       [--family ldo|mosfet|resistor|mcu|...] [--cat "品类名"]
                       [--market taobao|1688] [--taobao N] [--taobao-sample N]
                       [--taobao-json DIR] [--no-taobao] [--sort ...] [--json]
```

- `--qty` 默认 1；`--limit` 默认 8（每页解析条数）；`--pages` 默认 2。
- 比价段只在有 `picked` 且 `taobao_plan()>0` 时打印；`--taobao-json DIR` 把每个型号的原始结果写成 `pick_<型号>_<站点>_<时间戳>.json`。
- `--market 1688` 时表头与结论句自动改成「1688单只」「1688省 84%」。

## 失败模式与坑

1. **立创接口被 WAF 挑战**：`so.szlcsc.com/query/product` 对裸 `urllib` 返回 **HTTP 203 + JS 挑战页**（`_xvasu` / `_xvtsc=300` 脚本），`lcsc.py` 直接抛 `JSONDecodeError: Expecting value: line 1 column 5 (char 4)`。Edge 里同接口返回 200 JSON。本次验收用 `probe\taobao-pick\lcsc_bridge.py`（把 `Lcsc._post` 打补丁改走浏览器 fetch，**未修改 lcsc.py**）跑通，并设置 `BOM_CACHE` 到 probe 目录。**这是立创侧的环境问题，需要 lead 决定是否在 lcsc.py 里加浏览器兜底。**
2. **淘宝未登录时卡片 0 条**：`sample_info` 拿不到任何结果，`market_compare` 打印「淘宝无可用结果」；需先确认 Edge 已登录淘宝。
3. **`extension_error`**：本次 1 次（`LM5069MM-2/NOPB`）WebBridge evaluate 失败，代码降级为「取数失败」行，不影响其它型号。重试通常可恢复。
4. **型号当规格解析**：`pick.py "AO3400A"` 会把 `AO3400A` 解析成「连续漏极电流 3400A」→ 命中 0 条。要按型号找料得给规格词（`"N沟道 30V 5.8A MOS"`）或 `--cat`。这是既有解析器的限制，未改。
5. **系列链接**：淘宝阻容常见"一条链接挂 200+ 阻值/容值"，标价是"一包(100 只)/一份"的起价。若不剔除，会把淘宝算成贵 100 倍；现在这类链接不给单只价，只标「✓ 可打样（系列链接）」。
6. **开发板混入**：搜 `STM32F103C8T6` 前 3 名是开发板（¥10-21），单只价完全不可比。已按 `_DEVBOARD_RE` 剔除。
7. **起订量**：淘宝阻容/芯片常见 `5000 只/份`、`2000 只/份`，比价时单只价很低但**买不到 1 只**；结论句会明确写「这个链接 N 只起、不能打样」。

## 未验证 / 风险

- 1688 只做了 2 个型号的比价（STM32F103C8T6 / STM32F407VET6），**1688 价格区间与起订量（阶梯价）仍未完整验证**（1688 阶梯价不公开，需人工询盘）。
- 淘宝 `价格` 排序 tab 点击无效（已在 `research/taobao-tool.md` 记录），比价依赖「按销量取前 5 条」而非全量低价，**不保证抓到最便宜链接**。
- 运费只能靠"包邮"关键词与价格阈值猜测，**未接入真实运费估算**。
- `--qty 11~100` 目前完全不比价，是否应给"中小批量也看一眼淘宝"未验证。
- 立创 WAF 若持续存在，`pick.py` 在没有浏览器桥的环境里无法出结果。
