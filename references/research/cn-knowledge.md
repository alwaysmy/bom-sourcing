## A. 配单 SOP（拿到 BOM → 下单，逐步可执行）

### A0. 总览

```
BOM 到手
  → A1 格式体检（字段齐不齐 / 位号 / 单位 / 封装）
  → A2 型号正名（写错字母、系列/后缀、封装变体）
  → A3 参数复核（降额、耐压、精度、温度、生命周期）
  → A4 可采性判定（现货/起订量/交期/是否停产）
  → A5 替代料裁决（必须原型号 vs 可替代 vs 可升级）
  → A6 数量与损耗（打样加抛料、量产按卷/阶梯）
  → A7 渠道分流（一张 BOM 拆成多条采购线）
  → A8 下单前检查（配单匹配率、MOQ、开票、运费）
  → A9 到货验收（丝印/批次/抽测）
```

### A1. 格式体检——先别搜价，先查 BOM 本身

行业里返工的头号原因不是买贵了，而是 **BOM 本身有错**。捷创（jc-pcba）在其 BOM 专题里列出的高频错误，可直接当检查清单用【二手】[^jc-bom]：

| 检查项 | 典型错误 | 判据 / 动作 |
|---|---|---|
| 型号 | `STM32F103C8T6` 写成 `STM32F103C6T6` | 一字之差是不同器件；型号必须逐字符核对，后缀（封装/温度/包装）单独一列 |
| 封装 | 写 `SOT-23` 实际是 `SOT-23-5` | 引脚数对不上就贴不了；封装列与 datasheet 的 Package 字段核对 |
| 替代料 | 缺货料没写可接受替代 | 备注列必须给"可接受替代型号或参数范围"，否则工厂只能停工等确认 |
| 位号 | 漏位号 / 同一位号出现两次 | 位号集合与坐标文件位号集合做差集，必须为空 |
| 单位 | `10kΩ` 写成 `10Ω`；`100nF` 写成 `100pF` | 数值差几个数量级；单位与数值拆成两列，程序化校验数量级 |
| 必填字段 | — | 位号、型号、封装、数量、厂商/品牌、备注（替代料/极性）六列齐【二手】[^jc-bom] |

> 【推断】对 agent 的含义：**A1 完全可以程序化**（字段存在性、位号唯一性、封装-引脚数一致性、单位量级校验），且不需要联网；这一步的投入产出比最高，应在任何检索/比价之前执行。

### A2-A3. 型号正名与参数复核

- **型号正名**：先按"制造商 + 基础型号 + 后缀"三段拆。后缀常编码封装/温度等级/包装形式，替换时必须逐段比对，不能只比基础型号。【推断】
- **参数复核的核心是降额（derating）**，这是中文资料里数值最硬的一块：
  - 陶瓷电容（MLCC）稳态工作电压 ≤ 额定耐压 **85%**【二手】[^derate]
  - 铝电解电容稳态工作电压 < 额定耐压 **90%**【二手】[^derate]
  - 钽电容稳态工作电压 ≤ 额定耐压 **50%**【二手】[^derate]
  - 稳压管（齐纳）功率降额：实际功率 < **0.5 × P**（同电流等级优先选反压最高型号）【二手】[^selguide]
  - 多芯连接器额定电流需降额使用【二手】[^selguide]
  - 通用参数余量：电压/电流/功率留 **1.2~1.5 倍**；电容耐压留 **≥1.5 倍**【二手】[^jc-param]
- **六个选型维度**（EET-China 硬件入门课，可直接当复核清单）【二手】[^eet6]：
  1. **复用性**——优先复用验证过的物料（可清库存，但会错过新器件优势）
  2. **成熟性**——广泛验证、生命周期良好、无 EOL、参考设计多
  3. **适配性**——电气/环境参数满足 + 降额 + 空间无干涉
  4. **替代性**——尽量有 Pin-to-Pin 替代，否则出货风险（文中案例：一款板卡先后换三家 32 位 MCU，项目拖凉）
  5. **采购性**——价格、交期、无 EOL、供应商可得性
  6. **归一性**——量产时减少物料种类（如全用 1% 电阻减少一种料），量上去才好谈价

### A4. 可采性判定

- 判定顺序：**在产/停产 → 现货 → 起订量(MOQ) → 交期 → 价格阶梯**。【推断】
- 缺货不是一种状态而是两种，处置完全不同【二手】[^jc-shortage]：
  - **交期拉长** → 提前下单、分批锁产能
  - **长期停产** → 尽快找替代或**锁定尾批**
- BOM 变更的"时间窗口"（打样只有 3-5 天）【二手】[^jc-bom]：工程资料处理阶段改 BOM 成本最低（只是改文件）→ 物料采购阶段改，已买料可能无法退 → 贴片阶段改要停机换料重编程并引入混料风险 → 焊完才发现，BGA/QFN 拆下基本报废。**结论：一旦进入贴片环节不再改 BOM。**

### A5. 替代料裁决（详见 B 节）

一句话判据：**封装优先（Pin-to-Pin）→ 参数等效或优于 → 品牌/渠道可信**。三条不满足任何一条就不要替【二手】[^jc-sub]。

### A6. 数量与损耗——这是最容易算错的一步

行业通行的 SMT 抛料（损耗）率，按元件类型分档【二手】[^jc-loss]：

| 元件类型 | 行业损耗率 | 工程师应对 |
|---|---|---|
| 常规阻容感（0402 及以上） | 0.3%–0.5% | 每款多备 5–10 颗 |
| 微型元件（0201 / 01005） | 0.5%–1.0% | 多备 10–20 颗 |
| BGA / QFN 等 IC、贵重芯片 | **零损耗或接近零**（不允许抛料） | 先确认工厂政策再精确备料 |
| 连接器 / 异形件 | 0.5%–2.0% | 提前沟通供料方式 |

- 业内底线口诀【二手】[^jc-loss]：**"阻容类千分之三，IC 不允许丢料"**。
- 三种损耗承担模式：①按固定损耗率加单；②按单价分档加**数量**（单价<0.1 元加 10 颗，0.1–0.2 元加 8 颗，≥1.0 元加 0 颗）；③平台基础库整盘上机、损耗由工厂承担（嘉立创等对单价 ≥1.0 元的元件采用零损耗原则）。
- **散料/剪带料上机损耗高于编带料**，需额外备份。
- 【推断】对 agent 的含义：报"建议购买数量"时必须带上损耗模型，且**贵重芯片不能按百分比加**，否则要么少料要么浪费。

### A7-A8. 渠道分流与下单前检查（详见 C 节）

- **立创 BOM 配单的三色匹配状态**【二手】[^lcsc-bom]：绿色"完全匹配" / 黄色"待确认"（如精度不符）/ 红色"无法匹配"（自定义命名器件）。**红色必须人工干预，不能跳过**；之后还要核查库存与 MOQ。
- **嘉立创手动配单的输入格式（官方原文）**【官方】[^jlc-match]：**"IC 直接输入型号；阻容直接输入值，值的参数用空格区分，例 `10K 5%` 或 `100PF 10V`，用别的符号可能找不出来。"**
- 嘉立创 BOM 匹配界面三区语义（官方）【官方】[^jlc-match]：一区=匹配成功项（**以黑色字体为最终要贴的型号**，需人工检查确认）；二区=未匹配，需点"手动匹配器件"；三区=2D/3D 预览（PCB 资料解析不完整时不显示）。
- **立创商城 ≠ 嘉立创，库存与价格彼此独立**【官方】[^lceda-order]：可贴元件只有"基础库/扩展库/推荐库"中的一部分；**在立创商城买的元件不能和 PCB 一起寄送**。

### A9. 到货验收

见 D 节踩坑 #1–#6；核心三条：看丝印/边沿/引脚、看批次日期码一致性、关键料抽测或送检。

## B. 替代料规则（按品类：必须一致 / 可放宽 / 可升级）

### B0. 风险分档（可直接作为 agent 的默认策略）

捷创把替代风险分成三档，判据与"若必须替代要做什么验证"都给全了【二手】[^jc-sub]。这是本次找到的**最完整一份中文分档表**：

| 档位 | 品类 | 为什么 | 若必须替代，最小验证动作 |
|---|---|---|---|
| **高风险（不建议替代）** | MCU/主控 | 寄存器不同，**要改软件**；封装/引脚可能不同；换后要重做 EMC/安规认证 | 完整功能测试 + EMC 认证 |
| | 电源芯片（DCDC/LDO） | 输出电压/电流/纹波/开关频率/热性能须完全匹配 | 满载测试 + 温升测试 |
| | 晶振 | 频率/负载电容/精度/温度稳定性必须一致 | 实测频率 + 起振情况 |
| | 连接器 | 引脚间距/高度/插拔力/镀层厚度必须匹配 | 插拔测试 + 接触电阻测试 |
| **中风险（谨慎替代）** | MOSFET | Vds/Ids/Rds(on)/Vgs(th) 需等效或优于原参数 | 温升测试 |
| | 运放/比较器 | 带宽/压摆率/输入偏置电流/噪声密度需匹配 | 信号完整性测试 |
| | EEPROM/Flash | 容量/接口/时序需一致 | 读写测试 |
| **低风险（可替代）** | 电阻 | 同阻值/同精度/同封装/功率相同 | 只确认阻值、精度、功率 |
| | 电容 | 容值/耐压/**材质(X7R/X5R/C0G)**/封装一致 | 确认容值、耐压、材质 |
| | 二极管 | 正向电流/反向耐压/正向压降匹配 | 确认关键参数 |
| | LED | 颜色/亮度/波长/正向电压/封装 | 多颗时需**亮度一致性配对** |

> 注意上表的隐藏判据：**电阻电容写的是"同材质/同精度"，不是"同参数区间"**。MLCC 换材质（如 X5R→Y5V）容值虽同，温度特性与直流偏压特性差很多【二手】[^jc-param]（"X5R/X7R 与 Y5V 温度特性差异大，时序敏感电路慎用"）。

### B1. "不能只看一个参数"清单——来自 B站同类内容的高密度提纲

芯团网 B站视频《BOM替代别乱来！这几种小料换错，整机故障率暴涨》的简介本身就是一份**替代判据提纲**，逐条指出"只看 X 会踩什么坑"【二手】[^bili-tihuan]（视频 15:06，播放 2867，已核验存在）：

| 品类 | 只盯着 | 还必须看 |
|---|---|---|
| MLCC | 容量、耐压、封装 | 材质（温度特性）、直流偏压特性、ESR |
| LDO | 输出电压/电流 | **压差(dropout)、PSRR、噪声、输出电容稳定性**（输出电容 ESR 范围不对会振荡） |
| MOSFET | 耐压、电流 | 栅极电荷、Rds(on)@实际 Vgs、SOA、热阻 |
| 光耦 | CTR | **可能影响电源环路稳定性**（反馈环路补偿） |
| 晶振 | 频率 | 负载电容、ESR、起振裕量 |
| 连接器 | 插得上 | 插拔力、镀层、保持力、振动 |
| 电解电容 | 容值耐压 | **ESR、寿命、纹波电流、温度等级** |

> 同一 UP 主另一条讲翻新料的视频，把"翻新料为什么难发现"讲清楚了【二手】[^bili-fanxin]：翻新芯片**不是一上电就坏**，而是短时间看起来能用；拆机料/打磨重印料/批次造假料/降级料风险不同；**样机测试通过不代表可靠**，翻新料在量产阶段才暴露离散性故障；温度等级造假会导致客户现场随机死机。

### B2. 替代料验四步法（可作为 agent 的"替代建议"附言模板）

捷创给出的验证流程，参数阈值明确【二手】[^jc-sub]：

1. **参数对比**：对照规格书逐项核对（电压、电流、精度、封装、温度范围）；**偏差 >10% 需谨慎评估**
2. **功能测试**：替代料焊测试板跑全功能；与原装料数据对比，**偏差 <5% 为可接受**
3. **可靠性测试**：高低温（-20℃~70℃ 或产品工作温区）、老化（85℃×168h 或 48h）；**新物料电气参数漂移 <5%**
4. **批量验证**：先产 **10–20 片**，做完整功能测试 + 可靠性抽检，合格后才放量

配套的验证报告字段（可直接当数据结构模板）：替代料型号/品牌/批次/供应商、主料与替代料规格书对比表、功能测试数据（替代 vs 主料）、可靠性测试结果、验证结论（通过/不通过/有条件通过）、工程师签字、**存档至少 2 年（汽车电子 15 年以上）**。

### B3. 国产替代 4 条经验（缺货场景）

【二手】[^jc-shortage]：①先对参数再换料（逐项核对电压/电流/温度/封装，别只看"功能一样"）；②小批量验证再放量；③关注批次与一致性（国产物料批次间可能有差异，先定来料检验标准）；④**留双供应链**（国产作二供，与原渠道并行）。

### B4. 按品类的"必须一致 / 可放宽 / 可升级"清单

> 说明：B0/B1 是**有出处的原文判据**；下表 B4 是把上述判据按 13 个品类展开的**可执行版**，其中标【推断】的行为本文综合得出，未在任何单一来源中逐字出现，使用时应标记为"经验规则"而非引用。

| 品类 | 必须一致（不一致就不许替） | 可放宽 | 可升级（更好即可替） |
|---|---|---|---|
| 电阻 | 阻值、精度、封装、额定功率 | 品牌、TCR（非精密/非分压场合） | 精度更高、功率更大、TCR 更小、薄膜替厚膜（成本允许） |
| 电容（MLCC） | 容值、耐压（≥原值）、**介质材质**、封装 | 品牌、容差（±10%→±5% 可） | 耐压更高、C0G 替 X7R（容量足够时）、低 ESR 系列 |
| 电容（电解/钽） | 容值、耐压、极性、封装尺寸 | 品牌 | **ESR 更低、纹波电流更大、寿命/温度等级更高（105℃ 替 85℃）** |
| 电感 | 感值、饱和电流 Isat、额定电流 Irms、尺寸 | 品牌、DCR（非功率路径） | DCR 更小、Isat/Irms 更大、屏蔽替非屏蔽（EMI 更好） |
| 二极管（整流/开关） | 反向耐压 Vr、正向电流 If、封装 | 品牌、Vf（非效率敏感处） | Vf 更低、If/Vr 更大、恢复时间更快 |
| TVS | **反向关断电压 VRWM、钳位电压 VC、峰值脉冲功率 Ppp、结电容 Cj** | 封装（同尺寸下）、品牌 | Ppp 更大、Cj 更小（高速信号更好）；**VC 不得高于被保护器件耐压** |
| 三极管（BJT） | 极性(NPN/PNP)、Vceo、Ic、hFE 档位、封装/引脚序 | 品牌、fT（低频场合） | Ic/Vceo 更大、hFE 更高、饱和压降更低 |
| MOSFET | **极性、Vds、Ids、Rds(on)@实际 Vgs、Vgs(th) 档、封装/引脚** | 品牌、Qg（非高频驱动时） | Rds(on) 更低、Vds/Ids 更高、Qg 更小、热阻更低 |
| 运放/比较器 | **通道数、封装/引脚、供电范围、是否轨到轨、单位增益稳定** | 品牌、封装材料 | 带宽/压摆率更高、噪声密度更低、失调更小、Ib 更小 |
| LDO | **固定/可调类型、输出电压、封装/引脚、输出电容 ESR 适用范围** | 品牌 | 压差更低、PSRR 更高、噪声更低、静态电流更小 |
| DCDC | **拓扑、输入/输出电压、输出电流、开关频率（涉外围 L/C 选型）、封装/引脚** | 品牌、轻载模式 | 效率更高、纹波更低、内置保护更全、外围更省 |
| 晶振 | **频率、负载电容 CL、精度(ppm)、温度稳定性、封装** | 品牌、ESR（有余量时） | ESR 更小（起振裕量更大）、精度/温稳更高、有源替无源（需加成本与功耗权衡） |
| MCU | **内核/主频、Flash/RAM、外设集合、封装/引脚、供电范围** | 品牌、同系列新型号（寄存器兼容时） | 资源更大、外设更全——**但必须重做软件与 EMC/安规** |
| 连接器 | **引脚数、间距、针脚定义与排列、安装方式、高度** | 颜色、镀层厚度（非高插拔次数） | 镀金替镀锡、插拔次数更高、带锁扣 |

> 【推断】三条"不许替"的硬红线（综合 B0 与常识，供 agent 兜底）：
> 1. **安全/认证相关**（安规电容 X/Y、隔离器件、保险丝、TVS 在安规回路）→ 一律原型号，替代即失效认证。
> 2. **定时/时钟基准器件**（晶振、RTC 晶振、基准源）→ 一律原参数，否则频率/时间精度失控。
> 3. **固件绑定器件**（MCU、Flash、EEPROM、专用 IC）→ 换料等于换项目，必须走软件回归。

### C3. 成本结构差异（少量 vs 批量）

## D. 踩坑清单（12 条，每条含 现象 / 判据 / 规避动作 + 来源）

> 格式：**现象**（会看到什么）→ **判据**（凭什么认定）→ **动作**（下次怎么做）。标【二手】的为中文内容源原文观点，标【实测】的为本次亲手验证。

### D1. BOM 型号写错一个字母，整板报废
- **现象**：板子焊完功能不对，或工厂反馈"这个型号买不到/封装对不上"。
- **判据**：`STM32F103C8T6` 被写成 `STM32F103C6T6` —— 一字之差是完全不同的器件【二手】[^d-jcbom]。
- **动作**：型号逐字符核对；把"基础型号 / 封装 / 温度等级 / 包装"拆成四列，各自与 datasheet 对照。

### D2. 封装标注与实际器件不符（SOT-23 vs SOT-23-5）
- **现象**：封装列写 `SOT-23`，实际下单型号是 5 脚，贴片时引脚数对不上【二手】[^d-jcbom]。
- **判据**：BOM 封装列的引脚数与所选型号 datasheet 的 pin 数不一致。
- **动作**：封装-引脚数一致性做程序化校验；不确定时以 datasheet 的 Package 图为准，不凭印象写。

### D3. 替代料未标注 → 工厂停工等确认
- **现象**：原厂料缺货/停产，工厂停线，交期无限后延【二手】[^d-jcbom]。
- **判据**：BOM 备注列没有"可接受替代型号或参数范围"。
- **动作**：每个关键料在备注列写"可替代型号 + 可放宽参数区间"；按 B 节分档决定"不许替"的料（并提前锁尾批）。

### D4. 位号缺失或重复 → 漏贴/重复贴
- **现象**：成品少一颗料，或同一位号出现两次导致重复贴装【二手】[^d-jcbom]。
- **判据**：BOM 位号集合与贴片坐标文件位号集合做差集非空；位号有重复项。
- **动作**：投板前跑"位号集合对齐 + 唯一性"检查（纯本地校验，零成本）。

### D5. 单位写错，数值差几个数量级
- **现象**：`10kΩ` 写成 `10Ω`，`100nF` 写成 `100pF`【二手】[^d-jcbom]。
- **判据**：同一位号在不同版本 BOM 中数值突变 10³ 倍以上；或单位列与数值列混在一格。
- **动作**：数值与单位分列；对数量级跳变做 diff 告警。

### D6. 打磨/翻新料：外观"全新"，焊后偶发失效
- **现象**：省了料钱，良率暴跌，返工损失远超差价【二手】[^d-jc-fake]。
- **判据（七条外观法，来源原文）**【二手】[^d-eet-fake]：
  1. 表面有**打磨痕迹** → 假芯片无疑
  2. **引脚光亮如"新"** → 必为翻新料（正品引脚是哑光/规整的）
  3. 印字有**锯齿感**、字迹模糊、深浅不一、位置不正
  4. **生产日期与封装厂标号混乱**、生产时间不一
  5. **正面边沿是直角** → 打磨货（塑封脱模后边沿本应是 **r 角圆角**，打磨会磨成直角）
  6. **定位孔深浅不一**，或整个被打磨平
  7. 包装与正品有明显差异
  补充判据：丝印**用化学稀释剂能擦掉**的多为普通丝印假货（正品多为激光打标，擦不掉）【二手】[^d-eet-fake]。
- **动作**：只从原厂/授权代理/可信分销商采购；关键料做 X-ray / 开盖 / 电参测试；要求来料检验报告与可追溯文件【二手】[^d-jc-fake]。

### D7. "散新料"= 拆机翻新，不是新品
- **现象**：有人把"散新"当正品卖；价格便宜一截。
- **判据**：行业内"散新"即**拆机翻新货**，不能算全新【二手】[^d-gd32]（该页为搜索快照，原页已 404，判据本身在行业内通用）；同批次芯片可用 **UID** 辅助判断是否为翻新（UID 改不了）【二手】[^d-gd32]；国产 32 位 MCU 翻新件实测**不良率约 10%–40%**【二手】[^d-gd32]。
- **动作**：量产/关键料一律不用散新；维修场景可用但必须"多买几个备用"【二手】[^d-chinafix]。

### D8. 样机全过、量产全挂——翻新料的典型发作曲线
- **现象**：样机测试正常，量产后批量死机【二手】[^d-bili-fanxin]。
- **判据**：翻新芯片**不是一上电就坏**，而是短时间看起来能用；离散性故障在量产阶段才暴露；温度等级造假会导致客户现场**随机死机**。
- **动作**：关键物料做**供应商分级 + 小批验证 + 替代方案**；采购不能只看最低价；研发也要关注渠道与器件生命周期【二手】[^d-bili-fanxin]。

### D9. 淘宝"好评如潮"是刷的，不是质量证据
- **现象**：店铺评分高、评价多，但收到的料有问题。
- **判据**：评价中**无图文或重复话术**的是刷单痕迹；有效评价应带**实物细节图**【二手】[^d-tb-guide]。另看引脚是否有打磨痕迹、镀锡光泽是否不均、丝印字体是否模糊或有擦拭感；**正品新品应有均匀哑光或标准亮光质感**【二手】[^d-tb-guide]。
- **动作**：过滤无图文/重复话术评价；优先看带实物细节图的反馈；对低价异常（明显低于立创/代理报价）直接放弃。

### D10. 损耗没算 → 贴到一半物料不够，交期延误
- **现象**：工厂贴片中途说料不够，紧急采购耽误数天【二手】[^d-jc-loss]。
- **判据**：行业损耗率——常规阻容 0.3%–0.5%、0201/01005 为 0.5%–1.0%、**BGA/IC 零损耗**、连接器异形件 0.5%–2.0%；底线口诀"阻容类千分之三，IC 不允许丢料"。
- **动作**：下单前问清三件事（损耗谁承担？损耗怎么算？贵重芯片抛料怎么处理？）；低值料主动多备 5–10 颗；贵重芯片按零损耗精确确认；**散料/剪带要额外备份**。

### D11. 贴片阶段改 BOM → 停机换料 + 混料风险 + BGA 报废
- **现象**：打样时临时换料/改 BOM，交期崩、良率崩【二手】[^d-jcbom]。
- **判据**：BOM 变更窗口——工程资料处理阶段（成本最低）→ 物料采购阶段（已买料难退）→ 贴片阶段（停机换料重编程，混料风险）→ 焊完（BGA/QFN 拆下基本报废）。
- **动作**：把 BOM 冻结点写进流程：**进入贴片环节后不再改 BOM**；版本号（V1.0/V1.1）+ 文件名带日期，避免工厂拿旧版本。

### D12. 立创商城买的料不能跟 PCB 一起寄 / 库存与嘉立创独立
- **现象**：在立创商城买齐了料，以为会随嘉立创的板一起到；或"商城有货但嘉立创贴不了"。
- **判据（官方原文）**【实测-官方】[^d-lceda]："立创商城和嘉立创的元件购买是独立的，包括库存和价格都是独立的"；"在立创商城购买的元件**不可以**和 PCB 一起寄送"；"在立创商城有库存的元件，但在嘉立创无法贴或者没有库存"。
- **动作**：贴片料必须在嘉立创 SMT 下单时选购（看"可贴标识"/基础库-扩展库-推荐库）；分立采购的料走单独物流。

### D13（补充）. 扩展库按"型号数"收费，物料种类越多越贵
- **现象**：BOM 料号种类多，换料费/上料费叠加，小批量成本被吃掉【二手】[^d-jlc-ext]。
- **判据**：基础库不收换料费，**扩展库按 20 元/型号**计【二手】[^d-jlc-ext]。
- **动作**：做**物料归一化**（如统一用 1% 电阻、合并相近容值），减少型号数量——这与 EET-China 的"归一性"维度一致【二手】[^d-eet6]。

### F2. 用 B站 Web API 直连的最小可用做法【实测】

```
1) 先 GET https://www.bilibili.com/  （拿 cookie: buvid3, b_nut）
2) 再带 cookie 请求：
   搜索  https://api.bilibili.com/x/web-interface/search/type?search_type=video&keyword=<kw>&page=1
   详情  https://api.bilibili.com/x/web-interface/view?bvid=<BV号>
   Header: User-Agent(桌面 Chrome) + Referer: https://www.bilibili.com/
3) 不加 cookie 时：第一次 200 成功，第二次起 412 Precondition Failed
   → 412 后退避 3s、3s×2… 并重新 warmup 首页
```

- **不需要 wbi 签名**（本次 10 个关键词 × 20 条全部 `code=0`）。

### F3. `bilibili-api`（Python）安装实测记录

- PyPI 上的**真实包名是 `bilibili-api`**（v9.1.0，`requires_python>=3.8`，81 个历史版本，Homepage = `github.com/MoyuScript/bilibili-api`；`Nemo2011/bilibili-api` 为同一血脉的仓库名）。**叫 `bilibili-api-python` 会装不到。**【实测】

- 走官方 PyPI 也能解析到包，但**在 Python 3.14 下构建依赖失败**：
  ```
  AttributeError: 'build_ext' object has no attribute 'cython_sources'
  ERROR: Failed to build 'pyyaml' when getting requirements to build wheel
  ```

  根因：`pip download pyyaml --only-binary=:all:` 返回 `No matching distribution found` —— **pyyaml 尚无 cp314 预编译 wheel**，只能源码构建而失败。【实测】
