# 指标核对规则（为什么这样比）

> 规则来源：`research/spec-rules.yaml`（32 个器件 family，2267 行，含默认型号库与风险备注）+ `research/cn-knowledge.md`。
> 实现：`scripts/spec.py`。原则是**只比同物理量、同单位的数值**，抽不到就标 `?`，绝不假装通过。

## 1. 三条硬判据

### ① 参数必须带测试条件才可比（最高频误判）

同一个 MPN，不同厂家标的测试条件不同，直接比数值会得出错误结论：

| 例子 | A 家 | B 家 | 直接比的错误 |
|---|---|---|---|
| `AO3400A` Rds(on) | 48mΩ **@Vgs=2.5V** | 17mΩ **@Vgs=10V** | 以为 B 家强 3 倍 |
| `LM393` 传输延迟 | 300ns（onsemi） | 1.3µs（ST） | 以为 ST 慢 4 倍 |

→ 比对前先看条件：`@Vgs`、`@Id`、`@Ta`、测试频率。条件不同只能定性参考，不能当硬指标。
脚本层面：`paramLinkedMap` 的键里带条件的（如 `测试条件`、`@Vgs`）单独展示，不参与数值比较。

### ② 电压一律降额，MLCC 尤其狠

| 器件 | 降额阈值 | 后果 |
|---|---|---|
| MLCC（Class II：X5R/X7R/Y5V） | 额定耐压 ≤ 85% | 容值随直流偏压大幅下降（实测 1µF/6.3V X5R 加 3V 只剩 0.36µF） |
| 铝电解 | < 90% | 寿命随温度/电压指数下降 |
| 钽电容 | **50%** | 失效模式是**短路**，不是开路 |
| 稳压二极管功率 | < 0.5×P | 热击穿 |
| 通用余量 | 1.2–1.5× | 电流/功率/耐压 |

脚本行为：`spec.verify()` 在 MLCC/钽电容上，候选耐压 < 需求×1.25（MLCC）或 <2×（钽）时给 `i` 提示，
但**不淘汰候选、不降低把握**——因为 BOM 里写的常是"额定值需求"，不是工作电压；是否升档由人确认。

### ③ 品牌是最安全的降本维度，但替代风险按品类分档

同规格实测价差：`SS34` 达 15×、`1N4007` 7×、`AMS1117` 5×、`AO3400A` 3.2×。

| 风险档 | 品类 | 规则 |
|---|---|---|
| 高（不许替） | MCU、电源芯片（DCDC/LDO 主控）、晶振、连接器、光耦、隔离器 | 型号逐字符核对，不接受"同参数"替代 |
| 中（需验证） | MOSFET、运放/比较器、EEPROM/Flash、TVS | 参数 + 测试条件都要核，缺一不可 |
| 低（可替） | 电阻、MLCC、电感、磁珠、普通二极管、LED | 允许同参数换牌；**电容必须同介质材质**（X5R→Y5V 容值同而温度/偏压特性差异巨大） |

阻容感的"同规格"= **同值 + 同精度 + 同封装 +（电容）同介质 +（电容）同耐压档**，
不是"参数落在一个区间里"。

## 2. 数值比较的实现口径

| 物理量 | 解析 | 比较 |
|---|---|---|
| 阻值 | `10kΩ`/`1R`/`470`/`0603WAF1002T5E` 的参数字段 | 相对误差 ≤ 2% 视为同值 |
| 容值/电感 | `100nF`/`10uH` | 同上 |
| 耐压 | `16V`、`1.6V~2.6V`（取最大） | 候选 ≥ 需求 即通过 |
| 精度 | `±1%` | 候选 τ ≤ 需求 |
| 功率 | `100mW`、`1/4W` | 候选 ≥ 需求 |
| 频率 | `8MHz` | 同值 |
| 封装 | `0603`/`LQFP-48(7x7)`/`SMA(DO-214AC)` | 归一后比较，含别名表（SOP-8≡SOIC-8-208mil、SMA≡DO-214AC、TYPE-C≡USB-C 等）；`SMD`/`SMT` 这类过粗描述只提示不判定 |

### 输出标记

| 标记 | 含义 | 对把握的影响 |
|---|---|---|
| ✔ | 已核对通过 | — |
| ✘ | 明确不符 | 直接淘汰该候选 |
| `?` | 需求有、候选未标（如 BOM 未给精度、立创没填该参数） | 降为「需确认」 |
| `i` | 提示（未标精度、封装描述过粗、降额无余量） | 不影响判定，仅展示 |

**注意**：立创 `paramLinkedMap` 是卖家填的，缺项很常见。`?` 不等于不合格，但必须回原厂手册确认后才能下单。

## 3. BOM 侧的本地体检（零成本，先做）

按 `research/cn-knowledge.md` 的 A0 阶段，配单前先自查，能挡掉最高频返工：

1. **列完整性**：型号、数量、封装、位号、描述、备注 六列；缺列先补
2. **位号 vs 坐标文件**：位号集合必须与 Pick&Place 一致，缺一个就是漏贴/多贴
3. **单位量级**：`10k` 写成 `10000k`、`100nF` 写成 `100uF` 这类量级错，靠人工很难发现 → 对比同族参数的典型值域
4. **型号逐字符核对**：MCU/电源芯片差一个字母就是整板报废，风险最高的不是价格而是这个

## 4. 数量与备料

| 品类 | 备料比例 | 说明 |
|---|---|---|
| 阻容感二极管（0402 及以上） | 0.3%，至少 +5 颗 | 抛料率千分之三 |
| 0201/01005 | 0.5–1.0% | 小尺寸抛料率高 |
| IC / 连接器 / 光耦 | 不加 | 不允许丢料，缺就补料 |

`bom.py` 的 `order_qty()` 按此实现（`--no-spares` 关闭）。
另一个隐形成本：嘉立创 SMT 的**扩展库按型号数收费**，物料归一化（把 3 个 10k 合并成 1 个 C 号）直接影响报价。
